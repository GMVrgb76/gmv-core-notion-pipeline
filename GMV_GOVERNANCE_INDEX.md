## Deprecated or Non-Canonical References

The following generic filenames are non-canonical and must not be created as aliases:

- `PROJECT_VISION.md`
- `PROJECT_ROADMAP.md`

`GMV_PRODUCT_VISION.md` is the canonical product-vision source. `GMV_V2_EXECUTION_ROADMAP.md` is the canonical V2 execution-roadmap source.

## Agent Rules

1. Use the canonical GMV documents listed in this index.
2. Do not create duplicate alias files for canonical documents.
3. Do not copy canonical content into `PROJECT_VISION.md`, `PROJECT_ROADMAP.md`, or similarly generic filenames.
4. Update the canonical source when authorized; do not create a parallel replacement.
5. Treat this index as the filename-resolution authority for GMV governance and planning work.
